# ADR-001: Modular monolith для MVP

- **Статус:** принято
- **Дата:** 2026-09-23

## Контекст

MVP содержит связанные правила inventory, snapshot, baseline, diff, incidents и history. Их целостность и audit важнее независимого масштабирования.

## Решение

Создавать AssetGuard как один развёртываемый backend с чёткими внутренними модулями и одной PostgreSQL-базой. Межмодульные границы поддерживаются в коде и контрактах, но не через сеть.

## Последствия

- Меньше инфраструктуры и точек отказа на MVP.
- Проще обеспечить транзакционность: event, incident и history не расходятся.
- Внешние источники скрываются за `InventorySourceAdapter`.
- Извлечение модуля в сервис возможно только при доказанной необходимости после MVP.
