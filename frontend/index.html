Администрирование

Подключить компьютеры

Создайте отдельный ключ для каждого компьютера. После первой инвентаризации ключ навсегда привяжется к этому устройству.

Шаг 1 из 3

Создать ключ Agent

Секрет будет показан один раз. Скопируйте его в установщик сразу, не передавайте в общий чат.

Шаг 2 и 3

Установить Agent

  1. Передайте на компьютер файл AssetGuard-Agent-Setup-0.1.3.exe.
  2. Запустите его от имени администратора.
  3. Укажите адрес сервера с окончанием /glpi-agent, затем вставьте созданные логин и ключ.

После первой отправки откройте «Имущество и компьютеры»: там появится устройство и его данные.

Как работает Agent

GLPI Agent только собирает разрешённые характеристики компьютера. AssetGuard принимает данные, сохраняет доказательство и сравнивает его с эталоном.

Нет данных
1

Сбор

Agent читает BIOS, CPU, RAM, накопители и сетевые идентификаторы. Пользовательские файлы и пароли не собираются.

2

Безопасная отправка

Инвентаризация уходит в AssetGuard по HTTPS с ключом и защитой от повторной загрузки.

3

Сравнение

Backend сохраняет исходный отчёт, строит снимок и сравнивает серийные номера и состав с подтверждённым эталоном.

4

Решение человека

При расхождении создаётся инцидент с доказательствами «Было → Стало». Система не объявляет изменение кражей автоматически.
