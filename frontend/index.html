Шаг 1 из 3
Создать ключ Agent
Секрет будет показан один раз. Скопируйте его в установщик сразу, не передавайте в общий чат.

      
Шаг 2 и 3
Установить Agent
  1. Передайте на компьютер проверенный установщик AssetGuard Agent. Версия 0.1.8 предназначена для пилотной проверки и ещё не опубликована как подписанный релиз.

Запрос восстановления ждёт подтверждения 30 минут и не меняет карточку компьютера.

Импорт
Добавить или обновить имущество
Сначала AssetGuard покажет найденные строки, новые записи и обновления. До подтверждения реестр не изменяется.
  1. Выберите Excel или PDF.
  2. Проверьте распознанные позиции.
  3. Исключите ошибочные строки и подтвердите импорт.
Excel — до 5 МБ, PDF — до 10 МБ. Ошибки исправляются в исходном файле перед повторной загрузкой.
PDF-сканы могут использовать OCR. Всегда сверяйте результат с оригиналом.

Скачать текущий реестр

Без магии и скрытого доступа
Как работает Agent
GLPI Agent только собирает разрешённые характеристики компьютера. AssetGuard принимает данные, сохраняет доказательство и сравнивает его с эталоном.
Нет данных

    

      
1
Сбор
Agent читает BIOS, CPU, RAM, накопители и сетевые идентификаторы. Пользовательские файлы и пароли не собираются.

      
2
Безопасная отправка
Инвентаризация уходит в AssetGuard по HTTPS с ключом и защитой от повторной загрузки.

      
3
Сравнение
Backend сохраняет исходный отчёт, строит снимок и сравнивает серийные номера и состав с подтверждённым эталоном.

      
4
Решение человека
При расхождении создаётся инцидент с доказательствами «Было → Стало». Система не объявляет изменение кражей автоматически.
